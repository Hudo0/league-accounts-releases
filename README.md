# League Accounts — downloads

An offline League of Legends account manager for Windows. It keeps all your accounts in one place, shows their
ranks and win rates, and opens League on the right account through the Riot Client.

## Download

**[Download the latest version](https://github.com/Hudo0/league-accounts-releases/releases/latest/download/League-Accounts-Setup.exe)**

You can also pick a specific version on the [Releases](https://github.com/Hudo0/league-accounts-releases/releases) page.

## Install

1. Run `League-Accounts-Setup.exe`.
2. The installer isn't code-signed, so Windows SmartScreen may warn you. Choose **More info → Run anyway**.
3. Start **League Accounts** from the Start menu or the desktop shortcut.

To update, install a newer version over the old one. Your accounts are kept.

## Your data

Everything stays on your PC in `%APPDATA%\League Accounts`. Nothing is sent to any server, and passwords are
encrypted with Windows' own protection. Signing in always happens in the Riot Client, and you are responsible for
following Riot's Terms of Service with the accounts you manage.
